**How it was computed** (reproducible, read-only git):
- Fork points via `git merge-base`; per-PR unique increment via `git log`/`git diff` against the
  *true* fork point (not the stale GitHub base branch).
- "Overlap" = files the PR's unique increment touches that `main` also changed since the shared
  trunk (`git diff --name-only 4b9389b..main`, 53 files). File-level overlap is a **superset** of
  real conflicts — same file ≠ same hunks — but zero overlap guarantees a clean pick.

## Suggested morning workflow (per pick)

```bash
git switch -c pick/<name> main
git cherry-pick <sha…>            # from the table above
# resolve the (registration-line) conflicts, then the CLAUDE.md Verify gate:
bun run check && bun run test && cargo clippy --release --all-targets --manifest-path src-tauri/Cargo.toml -- -D warnings
# regenerate ts-rs bindings if a Rust type moved
```
Then close the corresponding old draft with a comment pointing at the new PR. The nightly loop can
grind through Waves 1–2 one pick per iteration if you'd rather not do them by hand — say so in
VISION.md or a night-log "next candidate".
