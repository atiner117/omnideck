# PR triage — the 30 open fable drafts vs current main (2026-07-26)

Deterministic merge-triage of every open draft PR (#18–#47) against `main` @ `c6ab9ef`
(post-#48 hardening, post-#49/#50/#51 docs+changelog). Produced by the nightly loop so the
morning review starts with answers instead of 30 red "conflicts" banners.

**How it was computed** (reproducible, read-only git):
- Fork points via `git merge-base`; per-PR unique increment via `git log`/`git diff` against the
  *true* fork point (not the stale GitHub base branch).
- "Overlap" = files the PR's unique increment touches that `main` also changed since the shared
  trunk (`git diff --name-only 4b9389b..main`, 53 files). File-level overlap is a **superset** of
  real conflicts — same file ≠ same hunks — but zero overlap guarantees a clean pick.

## TL;DR

1. **None of these PRs should be merged as-is.** They all pre-date the 2026-07-19 history rewrite:
   their merge-base with main is `c7c5067` (Jul 6) and they each carry ~15 duplicate commits of
   pre-rewrite history. **But** the duplicated trunk is *tree-identical* to main's rewritten one
   (`369ed3b^{tree}` == `4b9389b^{tree}` == `e134188`), so every PR's real content is just **1–4
   unique commits that cherry-pick cleanly-ish onto today's main.** Salvage = cherry-pick, retarget
   or re-open small PRs, close the old ones.
2. **#48 already re-implemented six of these.** Close them (verify first, column below).
3. **Eight PRs have zero overlap with main's changes** — near-guaranteed clean picks. Start there.
4. Four PR-less lane branches hold live content the drafts depend on (notably the **audio-switcher
   backend** and the **SettingDef table** that #44/#46 need). Accounted for at the bottom.

## Suggested morning workflow (per pick)

```bash
git switch -c pick/<name> main
git cherry-pick <sha…>            # from the table above
# resolve the (registration-line) conflicts, then the CLAUDE.md Verify gate:
bun run check && bun run test && cargo clippy --release --all-targets --manifest-path src-tauri/Cargo.toml -- -D warnings
# regenerate ts-rs bindings if a Rust type moved
```
Then close the corresponding old draft with a comment pointing at the new PR. The nightly loop can
grind through Waves 1–2 one pick per iteration if you'd rather not do them by hand — say so in
VISION.md or a night-log "next candidate".
